# Site public IAL · Jeli

Site statique (GitHub Pages) construit par `scripts/build_site_public.py` du dépôt de la plateforme à partir de `static/site.html`. `config.js` donne l'adresse de la plateforme vers laquelle mènent « Se connecter », la démo, les données et l'application. Les phrases en langue de l'exemple de conversation sont publiées en français tant que le comité linguistique ne les a pas validées.
